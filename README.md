# oxide-hq/.github

Organization-wide defaults for [oxide-hq](https://github.com/oxide-hq):

- [`profile/README.md`](profile/README.md) — the organization profile page.
- Community health files used by every repository that doesn't define its own:
  [code of conduct](CODE_OF_CONDUCT.md), [contributing guide](CONTRIBUTING.md),
  [security policy](SECURITY.md), [support](SUPPORT.md) and
  [issue templates](.github/ISSUE_TEMPLATE).
