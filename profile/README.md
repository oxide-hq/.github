**Oxide** is a Laravel-inspired web framework for Rust. It brings the things that make Laravel
productive — a service container, form requests, route-model binding and fluent HTTP tests — to
[Axum](https://github.com/tokio-rs/axum) and [Tokio](https://tokio.rs), with everything checked at
compile time instead of at runtime.

### Projects

| Repository | Description |
| --- | --- |
| [**oxide-framework**](https://github.com/oxide-hq/oxide-framework) | The framework workspace: `oxide-http` (extractors, error contract, `TestClient`) and `oxide-http-macros` (derives) |

> Oxide is in early development. APIs will change while the first phases land.
